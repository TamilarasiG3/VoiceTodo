# 🎤 Voice AI To-Do App

A simple and powerful **Voice-Based To-Do Application** built using **Node.js, Express, and JavaScript**.
Users can add tasks using **voice commands**, and get **time-based reminders** directly in the browser.

---

## 🚀 Features

* 🎙️ Voice input for adding tasks
* 🧠 Smart parsing (date & time detection)
* ⏰ Browser notifications (reminders)
* 📋 Task list display
* 💾 JSON-based lightweight database
* 🎨 Modern UI (Dark Green Theme)

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express
* **Database:** JSON file (`db.json`)

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/voice-todo.git
cd voice-todo
```

### 2️⃣ Install dependencies

```
npm install
```

### 3️⃣ Run the server

```
node server.js
```

### 4️⃣ Open in browser

```
http://localhost:3000
```

---

## ⚠️ Important Notes

* Works best in **Google Chrome**
* Voice recognition requires:

  * HTTPS OR localhost
* Notifications must be allowed in browser

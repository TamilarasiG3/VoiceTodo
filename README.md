🎤 Voice To-Do App
🚀 Overview

Voice To-Do App is a simple and powerful web application that allows users to:

Add tasks using voice input 🎤
Automatically split multiple tasks
Display tasks in a numbered list (1, 2, 3...)
Save tasks using a backend server
✨ Features
🎙️ Voice recognition (speech → text)
✂️ Auto split multiple tasks
🔢 Numbered task list
💾 Save tasks (Node.js backend)
🎨 Dark theme (black + green 👾)
🛠️ Tech Stack
Frontend
HTML
CSS (Dark theme UI)
JavaScript

🎯 How It Works
Click 🎤 Speak button

Say tasks like:

“Buy milk, finish project and call mom”

App will:
Convert voice → text
Split into tasks

Display as:

1. Buy milk
2. Finish project
3. Call mom
